# Advance Ayurved Centre — website

Next.js 16 (App Router) + Tailwind v4 + Framer Motion + Lenis.

- `npm run dev -- -p 3121` — local dev
- `npm run build` — production build (all pages are static)

Content lives in `src/lib/` (`site.ts` for NAP/contact, `treatments.ts` for condition + therapy pages, `team.ts` for doctors/staff/testimonials/blog list).
Images in `public/images/treatments/` are AI-generated placeholders — replace with real clinic photography before launch.
Items to confirm with the client are listed in `../advance-ayurved-centre/website-content.md` (section 15).
